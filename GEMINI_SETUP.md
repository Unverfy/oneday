# Настройка Gemini API

## Проблема
AI не работает, потому что нужен действительный API ключ от Google Gemini.

## Решение

### 1. Получите API ключ от Google
1. Перейдите на https://aistudio.google.com/
2. Войдите в свой Google аккаунт
3. Нажмите "Get API Key" или "Получить API ключ"
4. Создайте новый проект или выберите существующий
5. Скопируйте API ключ

### 2. Обновите API ключ в проекте
1. Откройте файл `src/constants/index.ts`
2. Замените `YOUR_GEMINI_API_KEY_HERE` на ваш реальный API ключ
3. Сохраните файл

### 3. Перезапустите проект
```bash
npm start
```

### 4. Проверьте работу
1. Откройте браузер на http://localhost:3000
2. Введите текст в поле ввода
3. Нажмите "Створити ідеальний день"
4. Должен сгенерироваться план дня

## Альтернативное решение
Если не хотите использовать Gemini API, можно:
1. Удалить вызовы AI из кода
2. Использовать только статические планы
3. Или интегрировать другой AI сервис
